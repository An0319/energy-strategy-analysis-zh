# energy-strategy-analysis-zh
# 中国能源变革与世界能源发展趋势分析

> 一份基于公开数据的全球能源格局战略分析报告。

## 关于本项目

这份报告是我作为独立研究者完成的全栈战略分析项目，覆盖 2020-2025 年中国能源变革与世界能源发展趋势（前瞻延伸至 2026-2030 年）。

**我的角色**：独立完成从数据采集、框架搭建、战略推演到报告撰写的全流程。

**核心内容**：
- 全球能源投资格局（3万亿美元规模分析）
- 中国能源变革全景（光伏/核聚变/氢能/新三样）
- 6方利益主体的动力分析与立场定位
- 2027-2030 关键技术窗口期识别
- 企业关系网络与产业链分析

**方法工具**：定量数据整理与可视化 + 结构化战略分析框架（利益相关方分析、结构分析、趋势判断）

**数据来源**：IEA、中国国家能源局等 50+ 公开数据源，所有数据均可通过参考文献链接验证。
